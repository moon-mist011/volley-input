# スパイク入力

校名と背番号（リベロ指定を含む）を登録してから、試合中に大きなボタンでスパイク情報を順番に記録する画面です。

- 記録校名・対戦校名、最大14人の背番号、最大2人のリベロを登録
- 登録選手の背番号をタップしてリベロ設定を編集
- 試合中は「選手 → 位置 → トス → コース → 結果」と一画面ずつ入力
- 試合中は現在の試合履歴を一覧で常時表示
- 入力途中の選択も端末内に保存し、再読み込み後は試合を自動再開
- 「戻る」で直前の選択を取り消し、最初の画面では直前の記録を取り消して結果を選び直し
- 登録画面でエンドラインが手前か奥かを選び、試合中はコース図を必要に応じて上下反転
- コース番号は左上1〜右下9。上下反転時は中心を軸に点対称の番号配置
- 試合終了で登録情報をクリアし、取り消しボタンで終了前の状態を復元
- 試合終了後は入力履歴ボタンから対戦カード一覧を開き、カードごとの詳細記録を確認
- 入力履歴ボタンから対戦カード一覧を開き、カードごとの詳細記録を確認
- 履歴は初期画面と試合中の両方で確認でき、新しい記録を先頭に表示
- 記録ごとの「入力済」チェック状態も端末内に保存
- 元サイト用の6桁コードを生成し、履歴のまとめコピーに対応

## ローカル起動

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開いてください。登録情報と履歴はブラウザのローカルストレージに保存されます。

生成したコードを元サイトのテンキー入力欄へ貼り付けるか、「元サイトを開く」から対象サイトへ移動できます。

## GitHub Pagesで公開

1. GitHubリポジトリの **Settings → Pages** を開き、Build and deployment の Source を **GitHub Actions** に設定します。
2. `main` ブランチへ変更をpushするか、Actionsタブから **Deploy to GitHub Pages** を手動実行します。
3. 公開URLは `https://moon-mist011.github.io/volley-input/` です。

公開後も、校名・選手・試合履歴は利用したブラウザ内に保存されます。GitHub Pagesへの公開によってクラウド同期されるわけではありません。

Service Workerでページ・スクリプト・スタイルをネットワーク優先で読み込みます。オンラインなら開くたびに最新ファイルを確認し、通信できない場合は一度正常に読み込んだファイルを使います。
